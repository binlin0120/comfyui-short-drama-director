# 模型档案（可切不可乱改）

本文件把模型选择从“pipeline.md 里写死 Wan2.2”升级为可切换档案。
切换模型是项目管理决策，不是提示词小事：画风、分辨率、帧数、负面词、
参考图状态都要在切换时重新校验。

## 1. 当前实机默认（不因本文件改动）

| 环节 | 模型 | 工作流 |
| --- | --- | --- |
| 文本 → 基图 | ZImage Turbo INT8 | `ZImage_Turbo_INT8.json` |
| 精修/改图 | Flux2 Klein 4B FP8 | `Flux2_Klein_4B_Image_Edit.json` |
| 图生视频 | Wan2.2 TI2V 5B GGUF | `Wan22_5B_TI2V_GGUF.json` |

默认语速/时长规则、三段式 API 分工、`scripts/comfy_pipeline.py` 参数都不变：
图 3-8 秒、16:9、30fps、角色定妆块复用。

## 2. 可选档案（提供给决策参考，不内置替代工作流）

| 档案 | 适合场景 | 提示词方言变化 | 本技能内置 |
| --- | --- | --- | --- |
| Seedance 2.5 | 快速出片、人物一致性较强的云端视频 | 单段式文生视频/图生视频，动作词可更细，画面文字仍难控 | 否，属于即梦/云服务 |
| MiniMax 海螺 H3 | 高质量动态、人物表情更活、情感戏 | 镜头语言词建议保留中文语义，减少英文生造词 | 否 |
| Wan 3.0 本地 | 本地可控、长镜头潜力 | 三段式思路保留，但新旧版本输入输出节点可能不同 | 否，需按新工作流适配 |

只写了“提示词方言变化”和“内置与否”，没有编造可选模型的下载地址或精确文件名；
型号仍在快速迭代，落地前必须以对应官方模型卡和 ComfyUI 社区页面为准。

## 3. 档案字段约定

项目分镜 JSON 顶层写当前档案：

```json
{
  "model_profile": {
    "id": "wan2.2-local",
    "route": "z-image -> flux2-edit -> wan2.2-ti2v",
    "source": "local-comfyui",
    "note": "当前实机默认，其他档案必须单独立项验证后再切换"
  }
}
```

切换档案时必须同时更新：

- 分镜 JSON `model_profile`；
- 每镜 `resolution`/`fps` 对应的期望帧数；
- 画面风格块与统一负面词（按新模型方言调整）；
- 定妆照和参考图状态（新模型可能改变人物质感，必须重新过 `REF`）；
- 配音/字幕/拟音流程不变，因为它们和画面模型解耦。

## 4. 切换纪律

- 默认档案可以稳定量产；可选档案先做 1-2 个测试镜头，用户确认后再铺开。
- 不允许在批量生成中途切模型；同一批镜头必须来自同一个 `model_profile.id`。
- 云端模型涉及账号、额度、素材上传，先向用户说明数据流向和费用风险。
- 模型档案写进项目 JSON，由质量门可查；不能只写在聊天记录里。
