# 批次、配音对齐与残片修复

短剧批量生产最容易失控的三个位置：不同场景混批、台词和 TTS 脱节、
下一镜与上一镜尾帧接不上。本文件把这三个位置从“临场处理”改成机械流程。

## 1. 批次单

生成前用 `scripts/plan_batch.py` 从分镜 JSON 生成批次表，按场景/光照/角色相近
把镜头归批。同一批里的镜头共享：

- 场景资产与光照（`scene_id`、光线氛围词）；
- 角色定妆块和参考图；
- 模型 profile 与画幅；
- 负面包。

批次的机械规则：

- 不同 `scene_id` 不混批；没有 `scene_id` 时至少按“场景/地点”分。
- 批量生成前先给用户出 `preview`（1-2 镜），用户明确说“继续/量产”后才铺开。
- 一批内任一镜头 FAIL 就停下，不带着已知问题继续跑后面的镜头。

批次表输出：

```powershell
python scripts/plan_batch.py `
  --shot-file "项目目录\分镜_第1集.json" `
  --role-file "项目目录\角色设定_最终版.json" `
  --output-dir "项目目录\计划"
```

生成 `批次表.csv/md`、`配音对齐表.csv/md`、`音色表.csv/md`、`计划汇总.json`。

## 2. 配音对齐单

配音对齐单按镜头列出台词/旁白、字数、镜头时长、预估语速：

- 预估语速超过 6 字/秒标 `WARN-注意`，超过 8 字/秒标 `FAIL-改稿`；
- TTS 前先改稿，再生成音色试听，不拿错误文本直接量产；
- 同一角色全部镜头用同一个 speaker/seed/instruct，试听后锁定；
- 旁白、台词、音效三条轨分开，字幕从校对后的 SRT 烧录。

## 3. 尾帧接力

相邻镜头必须连续，不能上一镜还在楼外，下一镜突然进室内。

- 每镜在 JSON 写 `tail_frame_desc`：镜头结束时画面里的人物位置、道具、光照方向；
- 下一镜的开场帧与上一镜尾帧一致，必要时先图生图微调再图生视频；
- 两镜之间要换场景时，用过渡镜（门/走廊/黑场）承接，不能硬切；
- 批量生成表里保留“尾帧接力”列，人工审批次时逐行核对。

尾帧接力不是文字要求，而是生产要求：生成下一镜时把上一镜尾帧图作为
图生视频输入，或先用编辑图统一到同一参考。

## 4. 残片修复流程

已生成片段不合格时不整段重跑：

1. 抽帧：`ffmpeg -ss <时间> -i 成片.mp4 -frames:v 1 残帧.png`；
2. 判断问题类型：崩脸/换装/场景崩坏/动作僵硬/尾帧不对；
3. 图生图精修残帧或改回角色定妆块，先修图；
4. 用修好的图图生视频，保留 seed 但只改动作词，尽量不动场景；
5. 复检 `qa_shot.py`，通过后替换对应镜头。

这条链路不允许跳步：直接重跑整镜等于把已确认的角色/场景风险重放一遍。

## 5. 量产门

只有同时满足以下条件才进入批量：

- `validate_project.py` 无 FAIL；
- 定妆照/参考图状态全部为 `REF` 或已声明 `TTV`；
- 用户看过 preview 并明确确认；
- 批次单、配音对齐单已生成并写入项目目录；
- 每个待生成镜头有 `tail_frame_desc`（或明确标注不需要接力）。
